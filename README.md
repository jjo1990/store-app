# Store App

Aplicación de tienda desarrollada con React + Vite + TypeScript.

## Tecnologías

- React
- TypeScript
- Vite
- TailwindCSS
- Zustand
- React Router DOM

## Funcionalidades

- Catálogo de productos
- Carrito de compras
- Gestión de estado global
- Diseño responsive

## Instalación

```bash
pnpm install
```

## Ejecutar proyecto

```bash
pnpm dev
```
